# Creative Mode

The Creative Mode website and the Creator Breakdown membership.

- `/` landing page: "Creative Mode by Martin Wang" with one button to Creator Breakdowns
- `/creator-breakdown` sales page

Built with Next.js and Tailwind, hosted on Vercel.

## Where to change things

- Brand colors and fonts: `src/app/globals.css`
- Prices, dates, guarantee: `src/lib/offer.ts`
- Landing page: `src/app/page.tsx`
- Sales page: `src/app/creator-breakdown/page.tsx`

## Run it locally

```
npm install
npm run dev
```
